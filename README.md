# LimitlessExterior
Website for Limitless Exterior — window cleaning, gutter cleaning, pressure washing and Christmas light installation in Etobicoke & the GTA.

- Netlify publishes the `Website/` folder.
- Pages are generated by `tools/build_site.py` (edit content there, then run `python3 tools/build_site.py`).
- Quote form uses Netlify Forms (form name: `quote`).
